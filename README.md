# 世界近視觀察室

繁體中文學生近視教育網站。歷史觀察視窗為 1996–2025，健康資訊查核至 2026-10-07。

## 網站

https://zuestrd20.github.io/global-myopia-student-guide/

純靜態 HTML/CSS/JavaScript，無追蹤器、無登入、無外部字型或程式依賴。測驗答案不儲存、不傳送。原創 SVG 圖解。

## 內容

- 30 年證據時間軸，不補造逐年數據
- 12 筆研究樣本、9 個國家或地區、19 筆近視／高度近視指標
- 年齡／地區／指標／關鍵字篩選及資料表
- Holden 2016 全球模型，2050 預測預設隱藏
- 台灣同年齡調查比較、3 個研究／公共衛生案例
- 概念、健康習慣、證據限制、7 題測驗、教師活動及列印學習單
- 每筆研究保留調查年與發表年、分母、定義、驗光、抽樣及不確定性

模型不是普查；地區样本不能外推全國；不同年齡與定義不能排名；高度近視是近視的子集合。未核對到的有效年齡分母或區間明確註明。Holden 2020 正文與表格、2050 區間正文與摘要差異亦已披露。

## 本機檢查

無安裝步驟。以靜態伺服器開啟 index.html。

```
python -m http.server 8000
node --check app.js
node --check data.js
node check-data.cjs
```

check-data.cjs 驗證資料、HTML 資產及以模擬 DOM 執行篩選、圖表切換、测驗與列印事件。這不是瀏覽器布局或無障礙認證；實際公開網站另以瀏覽器驗收。

## 更新資料

data.js 儲存 MYOPIA_DATA 與 MYOPIA_CONTENT。修改數值須同步核對原始來源、定義、樣本與時間，不可只替換百分比。原文連結於各卡片與來源章節可查。
